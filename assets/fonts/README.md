# PDF用の日本語フォント

IPAexゴシック Ver.004.01（`ipaexg.ttf`）を公式配布物から改変せず同梱しています。

- 公式配布ページ：https://moji.or.jp/ipafont/ipaex00401/
- 取得元：https://moji.or.jp/wp-content/ipafont/IPAexfont/ipaexg00401.zip
- ライセンス：同梱の `IPA_Font_License_Agreement_v1.0.txt`

ReportLabのTrueTypeフォントとして登録し、使用した文字のフォントデータをPDFに埋め込みます。OSへのインストールや、実行時のダウンロードは不要です。アプリを移動・配布する場合は、このフォルダとライセンスも含めてください。
